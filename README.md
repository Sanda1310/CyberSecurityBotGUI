🔐 Cybersecurity Awareness Bot – Part 2

 📌 Project Overview

The Cybersecurity Awareness Bot is a GUI-based chatbot application developed in C# using Windows Forms for the PROG6221 module. The purpose of this chatbot is to educate users about cybersecurity threats and safe online practices through interactive conversations.

This version expands on Part 1 by introducing a modern graphical user interface (GUI), keyword recognition, memory and recall functionality, sentiment detection, randomised responses, and improved conversational flow.

 🎯 Objectives

The chatbot was designed to:

* Educate users about cybersecurity awareness
* Simulate natural chatbot conversations
* Improve user interaction through a GUI
* Demonstrate Object-Oriented Programming (OOP) principles
* Implement intelligent chatbot features such as memory and sentiment detection

🖥️ Features

 ✅ GUI Interface

* Windows Forms graphical user interface
* Styled cybersecurity-themed layout
* Interactive chat display
* User-friendly controls and spacing

 🖼️ Cybersecurity Branding

* Cybersecurity-themed title and interface styling
* Professional chatbot appearance

💬 Keyword Recognition

The chatbot recognises cybersecurity-related keywords such as:

* Password
* Privacy
* Scam
* Phishing

The bot responds with relevant cybersecurity guidance and safety tips.

🎲 Random Responses

For topics such as phishing awareness, the chatbot randomly selects responses from predefined lists to keep interactions dynamic and engaging.

🧠 Memory and Recall

The chatbot remembers user interests and refers back to them later in the conversation to personalise responses.

Example:

* User expresses interest in privacy
* Chatbot remembers this preference for future conversations

😊 Sentiment Detection

The chatbot detects simple emotional expressions such as:

* Worried
* Frustrated
* Curious

The chatbot then responds empathetically and provides supportive cybersecurity advice.

 🔁 Conversation Flow

The chatbot maintains conversation context by supporting follow-up questions such as:

* “Tell me more”
* “Another tip”
* “Explain more”

⚠️ Error Handling

The application handles:

* Unknown inputs
* Empty messages
* Unsupported queries

without crashing or terminating unexpectedly.
